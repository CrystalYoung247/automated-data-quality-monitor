# Automated Data Quality Monitor

An Excel data validation and reporting solution built with Microsoft Power Automate Desktop to identify incomplete business records, track data-quality issues, and automatically generate exception reports.

The workflow helps improve data accuracy, record accountability, and operational visibility by identifying missing information that may otherwise delay business processes.

## Business problem

Incomplete business records can delay follow-up and reduce accountability. A team needs a quick way to find records with no assigned owner or department, without manually reviewing the spreadsheet.

## Solution

This desktop flow:

1. Opens a sample Excel workbook and reads the used worksheet cells.
2. Initializes counters and lists for each type of missing data.
3. Iterates through the worksheet rows.
4. Checks whether **Assigned Owner** (column 3) or **Department** (column 2) is empty.
5. Counts each issue and records its **Record ID**.
6. Generates a summary report and writes it to a UTF-8 text file, overwriting the previous output on each run.

Both validation checks run within the same loop, allowing the automation to identify separate data-quality issues while processing the worksheet in a single pass.   

The sample workbook has a header row; it does not trigger the missing-field checks because the header cells are populated. The flow does **not** explicitly skip headers, so this is a limitation if the input format changes.

## Sample validation results

| Check | Count | Affected records |
| --- | ---: | --- |
| Missing Assigned Owner | 3 | BR-1002, BR-1006, BR-1012 |
| Missing Department | 2 | BR-1003, BR-1008 |

**12 business records** were evaluated. These are five missing-field findings across five distinct records in the included sample. The sample records are fictional and provided for demonstration.

## Running the workflow

Requires **Microsoft Power Automate Desktop** and Microsoft Excel on Windows.

1. Download or clone this repository.
2. Open Power Automate Desktop. The `.txt` file contains copied action text, **not a standalone executable or one-click flow installer**. If importing by pasting actions is supported in your environment, paste them into a desktop flow; otherwise recreate the actions as shown in the screenshot.
3. Update the paths in the **Launch Excel** and **Write text to file** actions to point to the workbook and desired report location on your computer. `YourUsername` in the text file is a placeholder; the referenced Downloads paths will not work unchanged.
4. Run the flow and open the generated report to verify the results.

## Testing and scope

- Ran the desktop flow against the included 12-record sample and confirmed both counters and corresponding Record ID lists.
- Confirmed the text report is generated and saved to disk.
- The flow currently checks **blank cells only**. It does not validate duplicates, invalid statuses, whitespace-only values, or malformed IDs.
- It uses the active worksheet structure and fixed column positions, so input column changes require updating the flow.
- It is a **manual-run desktop automation**, not a cloud flow or a scheduled monitoring service.
